# Lou’s Catering Services UI Design

A fictional **responsive catering services website UI concept** built with HTML and Tailwind CSS.

## Overview
Lou’s Catering Services is a front-end multi-page website design project created for a fictional catering business.

The project focuses on **responsive web design, multi-page navigation, modern UI layout, and user-friendly interface structure** across different screen sizes.

It includes a landing page, booking page, and quote request page with working page-to-page navigation and section-based navbar links.

## Features
- Responsive landing page
- Responsive multi-page website design
- Booking page UI
- Get a Quote page UI
- Page-to-page navigation
- Navbar links to sections using IDs
- Styled forms and buttons
- Mobile-friendly layout
- Hero sections with responsive content placement

## Built With
- HTML
- Tailwind CSS
- JavaScript (for navbar/menu functionality if used)

## Pages Included
- **Home Page** (`index.html`)
- **Booking Page** (`Booking.html`)
- **Get a Quote Page** (`GetaQuote.html`)

## Functionality
- Navigation between pages using buttons/links
- Navbar links scroll to page sections using IDs
- Responsive layout adaptation for different screen sizes

## Notes
This project is a **front-end UI design concept only**.

It does **not include backend functionality**, database integration, or actual form submission processing.

Forms and buttons are included as part of the interface design and front-end navigation experience.

## Purpose
Created as a practice project to improve:
- Responsive web design
- Multi-page website structure
- Front-end UI development
- Navigation and layout design
- User interface styling
